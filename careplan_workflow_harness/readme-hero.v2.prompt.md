# CarePlan README illustration prompt, v2

This revision turns the v1 miniature machine into a sparse systems graphical
abstract with an explicit authority boundary.

## Final style-transfer prompt

```text
Use the previous illustration only as a semantic reference. Preserve
synthetic order -> deterministic hard stop -> bounded typed draft -> schema
validation -> review pending -> human-only decision. Rebuild it as a rigorous
scientific-software graphical abstract.

Use a pure white background, flat orthographic layout, precise charcoal
hairlines, strict grid alignment, generous whitespace, and about 85%
grayscale. Use muted teal for valid and pending states, muted terracotta for
stopped states, and one ochre accent for the human authority boundary.

Show a neutral synthetic test sheet, a narrow eligibility gate with a blocked
branch, a thin rectangular automation enclosure containing only the bounded
draft provider and schema checks, a pending record, and a minimal human-review
role marker outside that enclosure controlling the only approve/revise split.
End with a small audit receipt.

Remove glass boxes, brass, levers, hands, conveyor belts, paper-card toys, wax
seals, desk scenes, dramatic lighting, robots, AI brains, neon, purple,
blue-black, hospital imagery, patients, drugs, clay rendering, logos, and
watermarks. Do not imply clinical deployment or autonomous approval.
```
