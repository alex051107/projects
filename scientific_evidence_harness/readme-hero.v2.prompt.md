# Dynamics Atlas README illustration prompt, v2

This revision removes the robot and gate-machine metaphor, then removes all
fabricated identifiers and metrics from the first clean draft.

## Final style-transfer prompt

```text
Use the previous illustration only as a semantic reference. Preserve
heterogeneous molecular sources -> Agent proposal -> deterministic
comparability checks -> accepted, review, or rejected evidence. Rebuild it as
a sparse computational structural-biology graphical abstract.

Use a pure white background, flat orthographic layout, accurate protein and
ligand render inserts, thin charcoal rules, ample whitespace, and about 85%
grayscale. Use muted teal for compatible evidence, ochre for provenance and
scope, and terracotta for mismatch.

Show two visibly different molecular evidence sources, a compact Agent-proposed
evidence card, and six restrained analytical panels. Make residue-axis mapping
the focal panel with thin correspondence lines and a few mismatches. Represent
identity, citation readiness, coverage, time compatibility, maturity, and
claim scope using short symbols and abstract scales. Branch to compact accept,
review, and reject outcomes.

Do not generate PDB-like identifiers, hashes, percentages, scores, time values,
resolutions, or other fake measurements. Use no long descriptive labels.
Remove robots, brass, machines, hands, desks, petri dishes, dramatic lighting,
AI brains, neon, purple, blue-black, glossy UI, clay rendering, decorative DNA,
logos, and watermarks. Do not imply that structural similarity proves
mechanism, thermodynamics, or kinetics.
```
